# Задание для ИИ: MCP для поиска вещей в магазинах

Сделай сервис (MCP), через который ассистент ищет настоящие вещи в Lamoda,
Ozon и Wildberries, и подключи его к карточкам образов.

Порядок работы:

1. Сначала проверь доступ к каждому магазину. У «Ленты» в этом окружении уже
   есть рабочий MCP — посмотри на него как на образец. Для трёх магазинов
   выясни: есть ли официальный API, нужен ли договор, что отвечают открытые
   страницы. Запиши выводы в TASK.md, в раздел «Что получилось на самом
   деле», прежде чем писать экран.
2. Если доступ есть — сделай MCP с одним понятным инструментом поиска:
   слова, цвет, цена от и до, размер, пол, категория, магазин.
3. Ответ на каждую вещь: название, картинка, цена, размеры в наличии, ссылка,
   магазин. Никаких выдуманных товаров — только то, что реально пришло.
4. В карточке образа добавь кнопку «Найти похожее»: берём описание вещи и
   ищем в трёх магазинах.
5. Кэш на 10–15 минут, чтобы не дёргать магазины на каждое нажатие.
6. Если магазин не ответил — показываем остальные и пишем простыми словами,
   какой магазин молчит. Ошибка не должна ломать экран.
7. Если доступ получить нельзя — не имитируй товары. Останови задачу и
   напиши в TASK.md, что мешает и какие есть варианты.

Проверь: запрос «белая рубашка оверсайз до 3000 рублей, размер M»; открытие
ссылки и совпадение цены; кнопку «Найти похожее»; отключение одного магазина;
повторный запрос в течение 10 минут.
