# Задание для ИИ: разбор в полный рост

Добавь разбор пропорций по фото в полный рост. Не ломай фото, разбор лица,
образы, гардероб, ключ и поиск вещей.

Требования:

- Экран «Разбор в полный рост», вход с первого экрана и с экрана разбора.
- Загрузка фото, проверки: один человек, видны голова и ступни, человек стоит
  прямо. Иначе — понятный текст.
- Два пункта: «плечи и бёдра» (шире / равны / уже) и «ноги и корпус»
  (длиннее / равны / короче). Без оценок и названий типов фигуры.
- Объяснение к каждому пункту простыми словами.
- Ручная правка каждого пункта, сохранение на устройстве, фото не хранить.
- Учёт фигуры в образах: строчка в «почему подходит» и в запросе к модели.

Проверь: полный рост принимается, по пояс — нет; правки сохраняются; после
перезагрузки разбор есть, фото нет; в образах появляется строчка про фигуру;
телефон.
