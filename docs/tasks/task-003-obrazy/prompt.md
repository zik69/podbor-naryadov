# Задание для ИИ: первые образы от ассистента

Добавь подбор образов по готовому разбору типажа и формы лица.

Требования:

- Кнопка «Подобрать образы» на экране разбора.
- Три–пять карточек. В каждой: картинка или описание (верх, низ, обувь,
  верхняя одежда), короткое название случая, блок «почему подходит» из двух-
  трёх пунктов, связанных с разбором (вырез, силуэт, длина, цвета).
- Кнопки «Нравится» и «Не нравится». «Не нравится» сразу заменяет карточку
  новым образом. «Нравится» сохраняет отметку на устройстве.
- Если человек поправил разбор руками, новые образы это учитывают.
- Пока идёт подбор — понятная загрузка и кнопка «Отменить».
- Ошибка сети или недоступный ассистент: простой текст и кнопка «Попробовать
  снова», без зависания.
- Не оценивай внешность, не используй слова «полный», «худой», «некрасиво».
- Не добавляй гардероб, примерку, покупки и погоду — это другие задачи.

Проверь: образы появляются, объяснения связаны с разбором, замена по «не
нравится» работает, отметки сохраняются, ошибка сети обрабатывается.
