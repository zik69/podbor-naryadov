# Задание для ИИ: свой гардероб

Добавь раздел «Мой гардероб» и сборку образов из своих вещей. Не ломай фото,
разбор, образы, ключ ИИ и поиск вещей.

Требования:

- Кнопка «Гардероб» в шапке и отдельный экран.
- Добавление вещи: фото, тип (верх, низ, обувь, верхний слой, платье), цвет,
  название по желанию.
- Список вещей с фото и удалением. Всё хранится только на устройстве,
  фото сжимаются.
- Кнопка «Собрать из моего»: 2–3 комплекта только из имеющихся вещей,
  с объяснением по разбору.
- Если не хватает категории — честно сказать, чего не хватает.
- С ключом DeepSeek сочетания подбирает модель, без ключа — правила.
- Фото вещей не отправлять в ИИ: только тип, цвет, название.

Проверь: добавление и удаление, сохранение после перезагрузки, комплекты только
из своих вещей, нехватка категорий, телефон, отсутствие фото в запросах к ИИ.
