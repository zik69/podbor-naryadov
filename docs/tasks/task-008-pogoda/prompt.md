# Задание для ИИ: погода и сезон

Добавь учёт погоды. Не ломай фото, разбор, образы, гардероб, фигуру, ключ
и поиск вещей.

Требования:

- В настройках поле «Город», по умолчанию «Тверь», хранится на устройстве.
- Погода через wttr.in (`https://wttr.in/{город}?format=j1&lang=ru`), без ключа.
  Таймаут 6 секунд, кэш 30 минут.
- Строчка на экране образов: «Сейчас в Твери +3°, облачно».
- Верхний слой по температуре: ниже 0 — тёплое пальто; 0–10 — куртка или пальто;
  10–18 — тренч или кардиган; выше 18 — без верхнего слоя.
- Строчка про погоду в «почему подходит» и в запросе к модели.
- Если погода недоступна — сезон по календарю и честный текст «погода недоступна».

Проверь: город сохраняется; погода показывается; верхний слой меняется
от температуры; при недоступном сервисе приложение не падает; телефон.
