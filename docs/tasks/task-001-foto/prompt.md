# Задание для ИИ: фото для разбора

Сделай первый экран приложения «Подбор нарядов»: загрузка фото с проверкой
качества. Приложения пока нет — начни с пустого проекта.

Требования:

- Один большой экран на русском языке: заголовок «Добавьте фото», короткая
  памятка и крупная кнопка «Добавить фото». На телефоне кнопка удобна для
  большого пальца.
- Загрузка: выбор файла и съёмка камерой. Поддержи jpg, png, heic, если браузер
  умеет.
- Памятка перед загрузкой: лицо целиком, смотреть в камеру, без тёмных очков
  и сильных фильтров, больше света.
- Проверка после загрузки: ровно одно лицо, лицо занимает не меньше десятой
  части кадра, яркость и резкость достаточные.
- Ошибки — простыми словами, без кодов. Пример: «На фото темно. Попробуйте
  у окна». Плюс кнопка «Попробовать другое фото».
- Приватность: фото остаётся на устройстве. Если нужна отправка на сервер,
  покажи короткое объяснение и кнопку «Отправить».
- Не показывай разбор типажа и образы — это следующие задачи.

Проверь: обычное селфи, тёмное фото, размытое фото, фото без лица, фото
с двумя лицами, замена фото.
