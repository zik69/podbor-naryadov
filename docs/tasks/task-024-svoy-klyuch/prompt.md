# Задание для ИИ: свой ключ ИИ в настройках

Добавь раздел настроек с ключом доступа к ИИ-сервису. Не ломай проверку фото,
разбор и образы.

Требования:

- Кнопка «Настройки» в шапке и отдельный экран.
- Поле для ключа, выбор модели, кнопки «Проверить ключ», «Удалить ключ».
- Ключ хранится только на устройстве. Никаких отправок на наш сервер.
- Без ключа приложение работает как раньше, на правилах.
- С ключом образы и объяснения приходят от модели.
- Понятные ошибки: неверный ключ, кончились деньги, сервис недоступен.
- Предупреждение: ключ виден всем, у кого есть доступ к компьютеру.

Сначала проверь, разрешает ли сервис запросы прямо из браузера (CORS).
Если нет — остановись и опиши, какой нужен сервер-посредник.

Проверь: без ключа всё как раньше, с ключом — тексты от модели, неверный ключ
даёт понятное сообщение, «удалить» возвращает на правила, после перезагрузки
ключ на месте, в файлах проекта ключа нет.
